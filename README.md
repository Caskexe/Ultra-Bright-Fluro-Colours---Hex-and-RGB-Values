# Ultra-Bright Fluro Colours

The brightest, most vivid colours in digital terms, we generally use full saturation and maximum brightness in the RGB colour space. That means at least one channel is FF (255), with the others at 00 or FF depending on the hue.

These are as bright as you can get on a standard RGB screen because each channel is either fully on (255) or off (0/128).
